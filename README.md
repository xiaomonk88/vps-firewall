# vps-firewall

适用于 Debian 12 / 13。按管理地址、省份、网段、单个 IP 限制 VPS 入站，提供中文终端菜单。支持 IPv4 / IPv6，默认同时保护 Docker / NAT 映射端口。

## 从 GitHub 一键安装

仓库：[xiaomonk88/vps-firewall](https://github.com/xiaomonk88/vps-firewall)。适用于 Debian 12/13，需要先发布至少一个正式 Release。

首次准备下载工具（仅需执行一次）：

```bash
sudo apt-get update && sudo apt-get install -y curl ca-certificates python3
```

复制下面整行执行，下载完成后安装最新正式版本；安装过程中可能询问管理 IP：

```bash
(set -e; f=$(mktemp); trap 'rm -f -- "$f"' EXIT; curl -fsSL --retry 3 https://raw.githubusercontent.com/xiaomonk88/vps-firewall/main/github_install.py -o "$f"; sudo python3 "$f")
```

需要明确指定管理地址时，在末尾 `sudo python3 "$f"` 后加 `--rescue '你的管理IP'`。安装后用 `sudo vps-firewall` 打开菜单。

## 更新版本

```bash
vps-firewall version              # 查看当前程序版本
sudo vps-firewall update          # 更新到最新正式 Release
sudo vps-firewall update --tag v1.0.0  # 指定版本
```

更新保留现有配置和数据，更新前备份程序及配置到 `/var/backups/vps-firewall/`。仅推送 GitHub 代码不会让 VPS 自动更新。还没有 `update` 命令的版本可重新运行一键安装命令。

本地开发、上传代码和发布新版本的步骤见 [GITHUB.md](GITHUB.md)。

## 手动上传、安装、打开菜单

把整个目录上传到 VPS，进入该目录执行：

```bash
sudo bash install.sh
sudo vps-firewall
```

首次安装会尝试识别当前 SSH 来源作为管理地址，支持自定义 SSH 端口和 IPv6。如果无法识别，会提示输入。也可以直接指定：

```bash
sudo bash install.sh 你的管理IP
# 多个管理地址用逗号分隔：
sudo bash install.sh '管理IP1,管理IP2'
```

重复安装保留已有配置。安装会自动安装依赖、校验并应用规则、启动服务和设置开机恢复。`sudo vps-firewall menu` 也能进入菜单。

```text
  ┌──────────────────────────────────────┐
  │ ◆ vps-firewall                       │
  └──────────────────────────────────────┘
  防护：已开启
  当前登录 IP：203.0.113.10

  ┌──────┬──────────────────────┬────────┐
  │ 编号 │ 功能                 │ 数量   │
  ├──────┼──────────────────────┼────────┤
  │ 1    │ 白名单管理           │ 3 项   │
  │ 2    │ 禁止 IP              │ 0 项   │
  │ 3    │ 直通IP地址           │ 1 项   │
  │ 4    │ 检查 IP 访问权限     │        │
  │ 5    │ 访问设置             │        │
  │ 6    │ 维护与日志           │        │
  │ 7    │ 暂停防护             │        │
  │ 0    │ 退出                 │        │
  └──────┴──────────────────────┴────────┘

请选择：
```

选择 `1 白名单管理` 后，进入下属菜单：`1 IP白名单`、`2 网段白名单`、`3 省份白名单`，每项显示数量，`0` 返回主菜单。直通IP地址是原管理登录地址，仅名称调整，仍用于保留管理访问权限。

主菜单、子菜单、选择列表和确认页面统一使用表格边框，每个功能独占一行；按中文显示宽度对齐，长地址自动折行。进入名单后，选择“添加”“移除”或“查看完整列表”；长名单和省份每页 12 项，用 `n` / `p` 翻页。支持批量添加、按序号或范围移除（如 `2-5`），省份可按编号或名称选择。

`0` 返回或取消；确认操作使用 `1` 确认、`0` 取消，默认取消。保存结果会显示在当前页面，不必反复按回车。主菜单和操作菜单直接按回车不会退出。每次修改立即校验、保存并生效；失败时保留或恢复旧规则。开启防护必须保留至少一个管理地址，涉及当前 SSH 权限会提示确认。

运行状态、刷新省份、恢复上一版、最近日志统一放在“维护与日志”中。

## 删除 IP 后的行为

删除后，若该 IP 不在其他白名单中，新的访问和既有入站连接的后续流量都会被拦截，不必重启服务或等待连接自然过期。程序不会再偷偷把当前 SSH 来源加入名单。

若该 IP 仍属于已放行的省份、网段、管理地址，或已开启全部 IPv6 放行，菜单会说明原因，并提供：

- **彻底撤销权限**：加入禁止列表；重复的单 IP 管理地址会一并移除，但必须保留另一个管理地址。
- **仅删除条目**：保留其他名单对它的放行。

也可以直接通过主菜单 `2` 禁止指定 IP。禁止地址不能与直通IP地址重叠；如果位于管理网段中，需要先调整管理网段。

默认对公网开放 ping，所以 ping 通不代表业务端口仍能访问。需要时在“访问设置”中关闭公网 ping 例外。删除权限后的 TCP 连接可能显示为超时，而非立即显示“连接关闭”；规则会丢弃它后续的入站数据。

## 常用命令

```bash
sudo vps-firewall                # 中文菜单
sudo vps-firewall status         # 配置、规则表和服务状态
sudo vps-firewall test           # 校验，不修改规则、配置或缓存
sudo vps-firewall reload         # 应用当前配置
sudo vps-firewall reload --force # 刷新省份数据后应用
sudo vps-firewall rollback       # 恢复上一版成功配置及本程序规则
sudo journalctl -u vps-firewall -f
```

配置文件是 `/etc/vps-firewall/config.toml`，也支持手动编辑后自动重载。下载失败且没有可用省份缓存时拒绝本次应用，保留现有规则。菜单能显示配置是否与上次成功规则一致；配置写坏时可从菜单恢复最近一次成功配置。

## 关闭与卸载

临时或长期关闭过滤：在主菜单中选择 `7` 暂停防护。关闭状态会保存，重启后保持关闭；只解除本程序的规则。

```bash
sudo bash /opt/vps-firewall/uninstall.sh
# 或在上传目录执行：sudo bash uninstall.sh
```

卸载会询问确认，删除本程序的规则、服务和安装文件。配置、缓存、历史会先备份到 `/var/lib/vps-firewall-uninstalled.XXXXXX/`，实际路径会打印出来。其他防火墙表保留。

## 保护范围与验证

- 保护 VPS 本机所有端口的入站；IPv6 也支持单 IP 和网段。
- 默认对经过 DNAT 的映射端口应用同一白名单，可在访问设置中关闭。普通路由转发、无 NAT 的容器直连、云安全组不由本程序管理。
- 服务器主动发起连接的响应流量可以返回；显式禁止 IP 会同时阻止该来源的响应。
- 本程序放行不代表其他防火墙也会放行。IPv6 邻居发现和相关 ICMP 错误等必要控制流量有例外。
- 省份归属依赖外部 IPv4 数据，不保证定位准确。
- 本地回归测试在 Windows 上执行；Linux 真实网络测试已提供，当前工作环境未执行。安装脚本会在目标 VPS 上使用 `nft -c` 校验规则，不能代替完整连通性测试。

详细实现、修复清单和测试方法见 [程序功能说明.md](程序功能说明.md)。
